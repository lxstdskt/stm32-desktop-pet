# 桌面陪伴机 - 工程文件用途与内容书写规范备忘录

> 本文档用于详细记录当前项目中每一个目录、每一类文件的存在意义及书写规范。当忘记某个文件负责什么时，随时查阅本文档。

---

## 1. 根目录全局文件 (Root Directory)

### 1.1 `README.md`
* **用途**：GitHub 仓库的主页展示，是给协作者、面试官及未来的自己看的第一份说明。
* **书写内容**：
  1. 项目一句话定位：基于 STM32F103 的桌面动态交互陪伴机。
  2. 硬件与算力约束说明（Flash 64KB, SRAM 20KB）。
  3. 软件架构分层逻辑与当前运行效果图（动图/照片）。
  4. 快速构建说明（编译命令、烧录方法）。

### 1.2 `AGENTS.md`
* **用途**：AI 编码助手（如 Codex、Copilot）的“紧箍咒”。代码插件在打开工程时会默认优先读取根目录下的规则文件。
* **书写内容**：
  1. 角色限定：要求 AI 扮演严格遵循 ANSI C (C99) 的嵌入式专家。
  2. 内存红线：明确禁止动态内存分配（`malloc`/`free`），局部大数组不得超过 256 字节，防止 20KB SRAM 发生栈溢出。
  3. 中断安全：严禁在中断处理函数（ISR）中加入阻塞延时（`delay_ms`）。

### 1.3 `开发流程与闭环测试.md`
* **用途**：日常开发的操作规程，保证每次改动都能在硬件上得到闭环检验。
* **书写内容**：
  1. 日常代码演进顺序（编写 -> CMake 构建 -> DAP-Link 烧录 -> 硬件信号测量 -> Git 存盘）。
  2. 硬件排查第一检查项（测量供电电压、检查 SWD 接线、测试地线回路）。

## 2. 方案与工程管理目录 (`产品定义、方案及工程管理/`)

### 2.1 `01_硬件接线与引脚分配表.md`
* **用途**：硬件物理管脚地图，严防接错引脚烧毁芯片或引起定时器冲突。
* **书写内容**：
  * 使用 Markdown 表格记录：外设名称、引脚编号（如 PC13、PB0）、复用功能（如 TIM3_CH3）、工作电压（3.3V / 5V）、供电方式（独立供电并共地）。

### 2.2 `02_各模块功能与接口约定.md`
* **用途**：功能契约文件。在编写代码之前，先确定对外暴露的函数签名与协议格式，作为给 Codex 的提示词（Prompt）基准。
* **书写内容**：
  * 只声明函数原型、入参、返回值和通信数据包 Hex 格式，不写具体实现代码。

### 2.3 `03_开发微观任务清单.md`
* **用途**：进度锚点看板。专门用于解决“AI 对话窗口重开后，搞不清开发具体进度”的问题。
* **书写内容**：
  * 采用任务复选框形式（`- [x]` / `- [ ]`），颗粒度精确到“调通某个函数的某一步”。开新窗口时直接粘贴当前正在进行的任务项给 AI。

## 4. 企业级代码分层目录 (`include/` 与 `src/`)

### 4.1 公有接口层 (`include/`) —— “对外的插座面板”
本目录下只存放需要暴露给其他模块调用的 `.h` 文件。
* **`include/bsp/` (板级支持包头文件)**：
  * 存放如 `bsp_led.h`、`bsp_oled.h`。只声明外设硬件控制函数（例如 `void BSP_LED_Toggle(void);`），绝对不能出现任何业务逻辑。
* **`include/app/` (业务逻辑头文件)**：
  * 存放如 `pet_controller.h`、`pet_events.h`。声明整个陪伴机的大脑状态机接口与事件枚举。

### 4.2 私有实现层 (`src/`) —— “对内的内部机械齿轮”
本目录下存放所有 `.c` 源文件，以及**仅在模块内部使用的私有头文件**。
* **`src/main.c`**：系统初始化主入口，负责按顺序拉起硬件与业务状态机，并在非阻塞主循环中轮询。
* **`src/bsp/` (底层驱动实现)**：
  * `bsp_xxx.c`：具体的 GPIO、I2C、PWM 寄存器或 HAL 库配置。
  * 私有头文件（如 `oled_font.h`）：大型字库点阵数组属于该驱动的内部零件，外部无权调用，必须私有收拢在 `src/bsp/` 下，防止污染全局作用域。
* **`src/app/` (业务状态机实现)**：
  * `pet_controller.c`：具体判断事件流转的状态机逻辑。
  * 私有头文件（如 `pet_motion_table.h`）：舵机动作序列数据表，仅供状态机读取，严禁外部篡改。
